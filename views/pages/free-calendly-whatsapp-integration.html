verified

The one Calendly plan every other tool needs you to upgrade past

Zapier, Integrately, and Pabbly Connect all require Calendly's paid Standard plan or higher just to connect — they rely on Calendly's Webhook Subscriptions API, which is gated behind a paid plan.

Watobot's Calendly integration works on Calendly's completely free plan. Instead of a server-side webhook, it listens for the booking confirmation directly in the visitor's browser, then reads the booking and invitee details through Calendly's regular read API — which free-plan accounts already have access to.

This is a real, live-tested capability, not marketing language: a test against a free Calendly account successfully read a custom phone-number question's answer end to end.

How it works

1

Connect your Calendly account

One click, standard OAuth — Watobot never sees your Calendly password.

2

Configure your message

Write your WhatsApp message template and tell Watobot which Calendly custom question holds the invitee's phone number.

3

Paste one line of code

Add a single <script> tag to your website, right before your existing Calendly embed code. Every booking after that automatically triggers the WhatsApp message.

quiz

One custom question on your event

Add a custom question to your Calendly event type that captures the invitee's phone number (e.g. "WhatsApp number") — mark it required so every booking includes it.

code

One line of code, once

No developer needed — copy one script tag from your Watobot dashboard onto your booking page.

smartphone

Sends from your own WhatsApp

Messages go out from your connected WhatsApp account, the same way all Watobot messages do — not a separate paid WhatsApp Business API number.
