Features

content_paste_off

No more copy-pasting phone numbers

No more copying phone numbers into WhatsApp Web to message someone — click the WhatsApp icon right next to the number, wherever you found it.

description

Template support

Create message templates once, then send pre-defined messages quickly instead of typing the same thing out every time.

history

Delivery history, with one-click retry

See the status of every message you've sent, and retry any failed one in a single click.

groups

Share one WhatsApp account with your whole team

WhatsApp itself caps a single account at 4 linked devices. Since the extension sends through your Watobot API key rather than linking as its own device, any number of teammates can use the same connected WhatsApp account.

How it works

1

Download & Install

Download the zip from GitHub, unzip it, then load it into Chrome via chrome://extensions → Developer mode → Load unpacked. Takes under a minute — full steps below.

2

Fill Watobot API Key

Connect your WhatsApp account on watobot.xyz, generate an API key from the dashboard, and paste it into the extension.

3

Start Messaging

Browse normally — the extension adds a WhatsApp icon next to every phone number it finds. Click it to message that number right away.

Installing the extension

This extension isn't on the Chrome Web Store yet, so Chrome requires one manual install step — it takes under a minute, and works the same way in other Chromium-based browsers (Edge, Brave).

  1. Download the zip file from GitHub.
  2. Unzip the downloaded file to a folder on your computer.
  3. Open Chrome and go to chrome://extensions.
  4. Turn on Developer mode (top-right toggle).
  5. Click Load unpacked and select the unzipped folder.
  6. Done — open any page with phone numbers on it to try it out.
